## General proof obligations and the strengthened descent lemma

Let T(n)=n/2 for even n and (3n+1)/2 for odd n, n≥1. Assume A(B) and consider all integers n∈[B,E) by global strong induction, or equivalently by the least hypothetical non-converging member of [B,E). A finite T path to m<n, an exact smaller preimage p<n with T^h(p)=n, or a T path from n that merges with a smaller p<n is sufficient to infer convergence. Individual computational tests of the residual set must be completed and independently certified before promotion of A(E); no independent ascending *execution order* is needed for the mathematical least-counterexample argument, but intermediate partial verification cannot support a published batch claim. An excluded n's proof always depends on A(n) and therefore on the assumed external basin plus all lower unresolved n. Witnesses must be positive and arithmetic exact.

For the first j steps let s_j count odd applications; then

    2^j T^j(n) = 3^s_j n + A_j

with A_0=0, and A_{j+1}=A_j if step j is even or A_{j+1}=3A_j+2^j if odd. Parity of the first j steps depends only on n mod2^j; two lifts of a fixed low-bit residue have the same s_j and A_j.

**Uniform high-base multiplicative descent theorem (proved):** fix B≥1, j≥1 and an odd-step count s. If

    (3B+1)^s < 2^j B^s,                                      (H)

then EVERY n≥B whose first j steps contain s odd steps descends strictly below its own n by some time ≤j. Proof: if any earlier iterate has dropped below n we are finished. Otherwise, for all 0≤i<j, T^i(n)≥n≥B. An even step multiplies by exactly 1/2; an odd step multiplies by (3+1/T^i(n))/2 ≤ (3+1/B)/2. Therefore T^j(n)/n ≤ (3+1/B)^s/2^j <1 by (H). No finite-n exception can exist. This is an elementary stronger-for-this-B form of the kind of multiplicative stopping criterion in Angeltveit's Theorem 4.1, not a claimed new theorem.

The exact-arithmetic fixture tests (H) for **each 1≤j≤58 at the largest integer s satisfying 3^s<2^j**. Since the left side grows with s, this proves that the ordinary slope-prefix condition 3^s<2^j is safe, at any j≤58, for every n≥B, without assuming B≥2^(2*58). The condition is NOT extrapolated beyond the finite verified j≤58 list. Prefix non-descent count is the old recurrence c[0,0]=1, c[j,s]=1_(3^s≥2^j)(c[j-1,s]+c[j-1,s-1]); it gives S_35=263841377 and S_58=615588850887706. A new parity prefix is one low-bit residue, so these are complete algebraic counts, not trajectory sampling.

**Exact Bařina-core exclusion:** write n=q2^k+r, q≥1 and r<2^k, and d=T^k(r), c=s_k(r). Then T^k(n)=q3^c+d. If 3^c<2^k and (3^c-2^k)<r-d, then T^k(n)<n for all q≥1. If a smaller r'<r yields the same pair (c,d), then n'=q2^k+r'<n has the same k-step image, so n and n' coalesce. Either certifies n by A(n). The exact fixture reimplements these conditions plus previously dead low-bit prefixes for k≤16; no performance claim is inferred from the successful 1720 count.

**General reverse-to-forward certificate:** for any parity word v of length h, with alpha odd steps, offset A_v, and 2^h<3^alpha, the reverse congruence y≡2^(-h)A_v (mod3^alpha) defines p=(2^h y-A_v)/3^alpha; at sufficient positive y, 0<p<y and T^h(p)=y. The 179 templates with 1≤alpha≤6, h≤9 cover precisely 335 residue classes modulo729, retaining 394. For a prefix of n with j steps, a odd steps and offset A, put y=T^j(n). When y meets the reverse congruence, the smaller-preimage inequality p(y)<n follows for ALL n≥B if

    c = 2^h*3^a - 3^alpha*2^j ≤ 0,
    c*B + (2^h*A - 2^j*A_v) < 0,
    2^h*3^a*B + (2^h*A - 2^j*A_v) > 0.

These are exact integer inequalities, and the last ensures p>0. The equality of the prescribed forward parity word follows from the affine congruence by induction modulo 2. This rule is generalized *path merging*, NOT a novel form of reverse Collatz theory. The bounded fixture tests its formulas and actual shortened-map paths on 200 CRT-constructed n≥B. Applying it to y=T^j(n), 1≤j≤12, can exclude starts not directly removed by reverse classes of n.
