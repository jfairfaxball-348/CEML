## Candidate A (champion): synchronising inverse-word cylinders — PROVED, local extra exclusions

Let w be a length-j *actual* parity word, with s=s(w) odd steps and additive offset C=C(w)>=0. Every positive n in its cylinder (n ≡ r_w mod 2^j) satisfies

    T^j(n) = (3^s n+C)/2^j.

**3-adic erasure lemma (proved).** For any a<=s, the image y=T^j(n) modulo 3^a is fixed by the parity word alone:

    y ≡ C*(2^j)^(-1) (mod 3^a).

Proof: 3^s n is divisible by 3^a; 2 is invertible modulo 3^a. Thus *all* 2^j-lifts n share the same image residue, regardless of initial n mod 3^a. This is a strong constraint on admissible inverse tails; no new conditional convergence is assumed in deriving it.

**Uniform odd-inverse escape theorem (proved).** Assume s>=1, C*2^(-j) ≡ 2 (mod 3), 2*3^s<3*2^j, and

    (2*3^s-3*2^j)*B + 2*C-2^j < 0.

For every positive n>=B having parity word w, y=T^j(n) satisfies y≡2(mod 3). Therefore p=(2y-1)/3 is a positive **odd** integer with T(p)=y. The displayed strict inequality is precisely 2y-1<3n at n=B. Its slope coefficient is negative, so it stays strict for all n>=B; hence 0<p<n. Under external A(B) and strong induction, the whole word-cylinder is safe to skip. Every inequality is signed and strict; equality is not accepted. There is no claim that y<n; in fact the example below has y>n. For the general inverse template with length h, a odd steps and offset D, the analogous candidate is

    p(n) = [2^h 3^s n + 2^h C - 2^j D] / (2^j 3^a).

It requires the exact image congruence, parity-template compatibility, positivity and strict p(n)<n. If s>=a the congruence can become independent of the input 3-adic residue; this is the language-generalisation proposed for R3E21-13, **not yet proven to give a global saving**.

**Completely exact high-base witness beyond the inherited local exclusions.** Let n=B+6395=2392518188130438748411. Direct 22-step arithmetic gives (j,s,C)=(22,14,10360925),

    T^22(n)=2728304940644277689471 > n,
    p=(2*T^22(n)-1)/3 = 1818869960429518459647 < n,
    T(p)=T^22(n).

The entire nonempty congruence class n' ≡ 6395 (mod 2^22), n'>=B, has this parity word and the same strict odd-predecessor property. For each integer q>=0, with n'=n+q*2^22, the image is T^22(n')=T^22(n)+q*3^14; p(n') is integral, odd and <n'. The interval [B,E) contains **144834950415984** integers in this raw cylinder. **That is NOT its marginal remaining count**: nearly all may already be excluded by another rule, and the existing 72-step test removes many deeper subcylinders.

The representative n passes all *preserved* depth-12 root/simple/equal-terminal masks, initial mod729 inverse and j<=12 merge screens, and every 72-step slope-prefix test. Its input mod729 is 640. This proves there is at least one concrete integer omitted by the earlier *predicate* but caught by this new deeper uniform family theorem; it does **not** prove that the inherited global **upper bound** can numerically be decreased by one without recomputing the upper-bound transfer on the same partition. ## Candidate B: finite coalescence-equivalence quotient and representative cover — VALID LEMMA, SCALE UNKNOWN

Define x~y iff there exist j,h>=0 such that T^j(x)=T^h(y). This is an equivalence relation: reflexivity is immediate, symmetry swaps paths, and transitivity follows by advancing two equal-tail paths to their common later iterate (the deterministic map permits composition). Any finite or finitely symbolically certified class with one **independently settled representative** has every member settled; one checked orbit plus verified merging certificates can discharge the class. For example, T(3)=5=T(10) is an exact two-member same-time class. A more useful large class would need a parametric family of coalescence certificates and a proof that the representative set is small **after** applying the old sieve.

**Hostile limitation:** this is not a new path-merging theorem; it is a quotient/cover way of organising already-known certificates. A claimed factor-100 saving from large class size is invalid until the cost of finding/validating the class, prior-verified representatives and full interval overlap is accounted for. The *minimum representative may still require an explicit long trajectory*. Angeltveit's path-merging sieve and Bařina's equal-terminal path work are significant prior art. An exact distinguishing test must produce parametric classes that combine several merger paths not captured by the old J12/729 predicate, together with disjoint in-window representatives; none has yet a full [B,E) count.

## Candidate C: residue-language finite automata — PARTIAL; a general forbidden-word idea fails

**CRT non-obstruction theorem (proved).** Fix any finite j-step parity word w and any residue t mod 3^a. The parity word determines precisely one n mod2^j, and gcd(2^j,3^a)=1. CRT produces infinitely many positive n realising both specifications, arbitrarily far above B. Thus no fixed *input-only* parity-language / input-3-adic incompatibility can forbid a word on all large starts. It also cannot obtain an exclusion solely by pretending those independent restrictions correlate. The fixture exhibits a length-16 all-odd parity prefix simultaneous with an allowed mod729 residue.

**Long-growth obstruction (proved).** For every finite H, positive starts n≡-1 mod2^H have the first H shortened-map steps all odd. Along this path T^j(n)=(3^j(n+1)-2^j)/2^j > n for 1<=j<=H. Hence there is **no fixed finite H** at which every positive integer drops below its own start. A finite-state ranking/potential claiming universal bounded-time descent from the parity symbol alone is false. This does not rule out *size-dependent* time bounds on a fixed finite [B,E), or new automata that encode congruences of future images rather than the independent input residues. Candidate A escapes the CRT obstruction because it makes a **future image** satisfy an inverse congruence.

**Research route:** track future-image 3-adic synchronisation together with slope/constant inequalities, search for graph components guaranteed to hit a decreasing reverse edge. A complete finite automaton must prove exact transition validity and exclude spurious cycles; an arbitrary 2-adic cycle of words need not correspond to a positive integer trajectory. No new automaton closure theorem is established here.

## Candidate D: potential, inverse tree and induction coverings — SCOPED OBSTRUCTIONS

A potential based only on a strict negative average log slope cannot certify an individual start: arbitrary finite all-odd prefixes exist (preceding theorem), and Tao's logarithmic-density almost-bounded orbit result is not pointwise. Similarly, an inverse predecessor template that gives p>=n is **not** inductively admissible simply because p ultimately maps to a common node. A reverse residue tree must preserve positivity, the actual odd/even template, integrality and a strict order or an independently discharged finite class representative. A numerical graph with each vertex pointing somewhere else, but no settled representative, may cycle and cannot be called a proof.

**Possible distinct route:** assemble a certified DAG/cover of whole numerical cylinders, where every edge either points strictly to a smaller start or to a class whose representative is independently settled. Prove disjoint first-hit coverage by exact interval intersections. Without a theorem making a small number of graph certificates cover enormous sets, this is a *research architecture*, not a skip rule or a savings bound.

## Full-interval count obligations and avoidance of double counting

Let S_old be the set of *actual* [B,E) integers not discharged by the precisely defined R3E21-4 masks and depth-72 slope predicate. Let F_j be the set whose **first** synchronising odd-inverse certificate occurs at depth j, after excluding old-killed values. Because first-hit sets F_j are disjoint,

    |S_old minus union(F_j)| = |S_old| - sum_j |S_old intersect F_j|.

But the inherited **330156319374735841** is a conservative majorant on S_old, not an exact |S_old|, and its proof is a nested max/min transfer. This could instead give a different bound without constructing exact |S_old|, but it must be fully recomputed with verified correct mask/phase accounting.
