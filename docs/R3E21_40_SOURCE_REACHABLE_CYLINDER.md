## Mathematical boundary

For T(z)=z/2 if even, (3z+1)/2 if odd, the successor of an odd input is 2 mod3. Each subsequent even T step multiplies the mod3 residue by 2, toggling 2<->1. A true state after q consecutive even steps since an odd step admits integer predecessor (2z-1)/3 **if and only if q is even**. Odd steps reset q to zero. In particular, the source's 24-step precompute resetting q=0 cannot certify a predecessor in the presence of incoming odd q; a fractional expression is not a legitimate smaller witness. The 167 states demonstrate source reachability of this discrepancy.

The 306/485 rational approximation has the correct strict direction: 3^306 < 2^485 as **exact integers**, implying 306/485 < log(2)/log(3). Thus 306i >=485f implies 2^i>3^f for positive i,f; this **alone does not prove T^i(n)<n** without the lifted affine offset and root hypotheses. We model search1's arithmetic pruning faithfully but do not independently formalise all its universal correctness. Similarly, doubleeven's bit pattern does not in isolation prove a smaller positive coalescing original input.
