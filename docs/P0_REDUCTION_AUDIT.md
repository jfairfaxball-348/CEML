# CEML-P0 — Exact reduction and acceleration audit
Scope: **cloud mathematical research only**. Nothing below authorises local scientific execution or an implemented skip. Map is **T(n)=n/2 if even, T(n)=(3n+1)/2 if odd** for n>=1. Standard C odd step is two basic operations. Distinguish T-steps from standard steps.

## Inductive certificate invariant
Let B>1 be an **explicitly accepted external base assumption**: each positive m<B converges to 1. To extend sequentially through [B,E), maintain provisional proof that every positive m<n converges (previous committed CEML batches plus lower already proved values of THIS same atomic ascending batch). For start n, a finite exact T path to any m<n suffices. The induction implication is valid because the lower m is already proved. At the end of a complete, integrity-verified batch with no unresolved member, commit a batch certificate atomically and promote contiguous E. If a prior batch remains uncommitted or contains a gap, a later batch cannot rely on it. Provisional evidence inside an interrupted batch never becomes independent durable prefix automatically. This inductive proof *inherits* its designated external base confidence.

Alternative stricter termination is m<batch.start (then previous committed base is enough) but can take longer; m<original n is valid ONLY for an actually ascending certified prefix. "Hits old external B", "below original n", "below batch start", and "reaches 1" are not interchangeable stopping statements.

## Minimum universally proved exclusion predicates
Rules evaluated in *deterministic non-overlapping priority order*; each predicate is only applied at a point n for which all smaller positive m are already certified as above. Decimal or big-integer representation may not overflow.
- **E2**: n>1, n%2==0; T(n)=n/2<n. Predicate integer `n % 2 == 0`.
- **Q4**: n>1, n%4==1; n=4k+1, k>=1. T(n)=6k+2, T²(n)=3k+1<n. Predicate `n % 4 == 1`; handle base n=1 separately. For 5, drops to 4.
- **P3**: n>1, n%3==2; n=3k+2 (k>=0), p=2k+1=(2n-1)/3 is a positive ODD integer with p<n and T(p)=n. If p is already certified convergent, then its trajectory contains n; so n converges. This is legitimate predecessor/coalescence, NOT a claim that forward T(n) immediately decreases. Predicate `n % 3 == 2`, exact `p=(2*n-1)//3`.
- **S2K** (generic proved residue prefix): for k>=1 and r in [0,2^k), derive a fixed T-parity word for any n≡r(mod 2^k), with a odd steps and exact nonnegative b such that `2^k*T^k(n)=3^a*n+b`. A class r may be removed for **all relevant n** only if `3^a*n+b < 2^k*n` holds throughout the class in the proposed coverage domain. For 3^a<2^k it suffices to show every positive n in the class above the minimum permitted n satisfies `(2^k-3^a)*n>b` in exact integers. If this is only eventually valid, record an exact threshold and handle small exceptions explicitly. This is a universal inequality proof, not sampling. A finite per-residue table is only a performance representation of these proved inequalities.
- **MIX**: Boolean conjunctions of already proved, independently justified predicates may be used to collapse enumeration but not counted twice or assumed to confer a new theorem. A new mixed modulus class must preserve the applicable inductive hypothesis.

Precedence **E2 > Q4 > P3 > S2K > explicit trajectory** (outside already-certified below-base values). Disjoint assignment by *first matching predicate*, even if multiple certificates exist. Ignoring S2K, only n≡3 or 7(mod12) survive these first three rules: 2/12=1/6 of positive starts asymptotically. This is an ACCOUNTING statement, not a measured trajectory throughput.

## Exact affine identity and parity invariants
For k consecutive T steps with parity bits e_0,...,e_{k-1}∈{0,1}, define a=sum e_i and b=sum over j=0..k-1 of `e_j * 2^j * 3^(sum_{i=j+1}^{k-1} e_i)`. Induction gives
`2^k*T^k(n)=3^a*n+b`.
For any fixed residue n mod 2^k, the first k parities are fixed; hence a,b are fixed; application must check exact divisibility. Composition of first block (k1,a1,b1), then second (k2,a2,b2) gives `(k1+k2,a1+a2, 3^a2*b1 + 2^k1*b2)`. This is the existing C1 affine principle, but *trajectory acceleration* is not by itself a proof of a full-residue exclusion.

Candidate exact acceleration: straight T as oracle; odd-only Syracuse `U(n)=(3n+1)/2^v2(3n+1)` on odd starts with precise T-step accounting; CTZ merging of even/odd runs and the n/(n+1) representation; small 2^k certified sieve; overflow-checked native arithmetic with GMP fallback; modest vectorisation only if independently tested. Derive tables FROM reference T and check by a separate oracle. Choose k/table tradeoff at P2; do not inherit enormous magnitude-optimised hierarchical k by default.

**Published method evidence:** Bařina (2025), https://doi.org/10.1007/s11227-025-07337-0, section 3 derives T stopping at first descent, switching between n and n+1 with CTZ, sieve modulo 3^k (3^2 improvement), and 2^k low-bit descent sieve; section 4 addresses work units, checksum and 128-bit overflow. https://github.com/xbarin02/collatz and https://github.com/xbarin02/collatz-sieve provide public implementations/tables; inspect exact meanings and table provenance before adopting. 2^16 table README reports 1720 survivors out of 65536, an author-supplied performance/coverage description, not P0 local proof. Higher 3^k sieves and mixed-class optimisation remain P1 proof/code-review candidates; initial engineering need not implement them.

## Tao theorem: exact boundary
Terence Tao, *Almost all orbits of the Collatz map attain almost bounded values*, Forum of Mathematics Pi 10 (2022), e12, DOI https://doi.org/10.1017/fmp.2022.8; preprint https://arxiv.org/abs/1909.03562. Let `Col_min(N)` be the minimum of the standard Collatz orbit. **For any** real-valued `f(N)` with `f(N)->+∞`, the property `Col_min(N)<f(N)` holds for a set of starting N of **logarithmic density 1** (relative reciprocal-weight asymptotics). This is not "each N descends below N" and does not show entry into a fixed, externally verified basin for every N. Exceptional N may be arbitrarily numerous and cannot be individually identified as safe by this theorem. There is **no uniform constructive skip rule for a specified n** for CEML from Tao's result. It informs motivation only and must never authorise a skipped integer.
