## 2. Exact domain theorem — arbitrary half-open interval

Let positive integer interval I=[L,H), L<H, with shortened T(n)=n/2 if even, (3n+1)/2 if odd. Define low-bit cylinder C(k,r;I)={n in I: n=r mod 2^k}, 0<=r<2^k. Define d=2^k, qlo=ceil((L-r)/d), qhi=ceil((H-r)/d)-1. Every member is uniquely n=r+d q with integer qlo<=q<=qhi. Empty iff qlo>qhi. Formula counts **qhi-qlo+1**, else zero. The ceiling is mathematical integer ceiling even for signed L-r; do not substitute truncation to zero. This also works on the partial last work unit.

**Binary splitting theorem.** C(k,r;I) is exactly the *disjoint union* of C(k+1,r;I) and C(k+1,r+2^k;I): the integer q in n=r+2^k q has unique even/odd parity. Both children use freshly computed exact qlo/qhi, not inherited un-clipped multiplicity. At k=0,r=0 the node is exactly I; induction gives exact disjoint cover of I by any finite full binary frontier of nodes with empty children removed. A validator that traverses every split and rejects missing or intersecting children proves **no start omitted, none duplicated**, without enumerating all starts. The proof depends solely on congruences/endpoints and is independent of Collatz convergence.

**Authenticated parity-affine theorem.** For fixed k,r, let s be the count of odd inputs in the genuine first k steps from n=r (permissible r=0 solely for mathematical prefix derivation), and let C be the nonnegative carry recursively defined by (s,C)=(0,0), and for step j=0,...,k-1: if current parity odd then s'=s+1, C'=3C+2^j; if even then s'=s,C'=C. The first k input parities depend only on n mod 2^k. Therefore for every positive n in C(k,r;I), **2^k T^k(n)=3^s n+C**. Proof by induction on j, since the parity of T^j(n) is fixed by the first j+1 low bits and 2^j T^j(n)=3^{s_j}n+C_j. Equivalently, for n=r+2^k q, **T^k(n)=T^k(r)+3^s q**, including arbitrary large q, provided T is extended to zero for the r=0 algebraic derivation only. The verifier can reconstruct s,C with O(k) exact-integer operations, and need not trust reported coefficients.

**Universal strict-descent leaf.** A cylinder can be discharged by its fixed k-step prefix if and only if its smallest positive nmin meets (2^k-3^s)nmin>C and 2^k>3^s. Because the difference (2^k-3^s)n-C is then increasing in n, the inequality holds for EVERY actual member. It proves T^k(n)<n, NOT convergence to one by itself. An empty node is not a descent claim. Further authenticated coalescence/inverse proof leaves must reconstruct the entire true path, preserve signed positivity/integrality, and show 0<p(n)<n at all actual endpoints/throughout the affine cell; otherwise split the cell or refuse. For affine comparisons, endpoint checking is sufficient only after proving the formula, congruences and fixed parity uniformly on that cell. A hash, worker's claimed leaf count, or isolated sample is never accepted as a proof.

**Finite global induction.** Suppose A(B) asserts convergence for every n<B. If each n in [B,E) has an independently verified exact path of strict descent T^j(n)<n, or independently verified true tail coalescence T^j(n)=T^t(p(n)) with integer 0<p(n)<n, then all n in [B,E) converge by strong induction on n. This logical proof can be assembled after arbitrarily scheduled units are all covered; any missing unit blocks the *global* conclusion. A single unit may independently prove its members' smaller-witness facts, but if it depends on unverified n>=B it may not assert convergence of that unit in isolation. The accepted frozen CEML-FRONTIER-2 operational protocol separately requires a contiguous committed prefix; this future proof-assembly idea does **not** amend it.

**Non-overlapping fixed-width task map.** B is divisible by 2^40. Put U=2^40, W=E-B, Q=floor(W/U)=**552501489**, R=W mod U=**350507499520**, strictly 0<R<U. Allocate full units [B+iU,B+(i+1)U) for 0<=i<Q, then partial [B+QU,E). Their union is [B,E), pairwise disjoint, precisely Q+1=**552501490** task IDs, **552501489 + 350507499520/1099511627776** fractional work-unit equivalents. Proof is integer Euclidean division W=Q U+R and half-open interval adjacency. Within any task, use the above low-bit tree with *its* exact L,H, never a global prefix result assumed valid only for starts below L.

**Concrete truncation counterexample.** In residue r=1 modulo 16, s=2,C=7 at k=4; T^4(1)=1, so 1 has NO strict 4-step descent, whereas T^4(17)=10<17. The true affine slope 9/16<1 alone does not imply universal descent from n=1, and a leaf verifier that ignores nmin or treats all members of the same low-bit residue as having identical descent truth is false. Likewise a final partial interval must clip its qhi; trusting a full 2^40 unit count silently asserts coverage beyond E, not a proof of exactly [B,E). A lookahead bitmap's allowed high-bit choices must be intersected with the exact [qlo,qhi] slice, not reinterpreted as unrestricted high bits.

## 3. A prospective proof DAG and hostile verifier

A claim record would contain schema/map/base tier and evidence hash, exact [L,H), task ID or final-partial index, source/algorithm/build revisions, complete exception accounting, and a content commitment. Proof nodes would be typed: EMPTY; SPLIT(k,r, two children); DESCENT(k,r,s,C,nmin, inequality and genuine parity); COALESCENCE(k,r, authenticated rational/integer affine p and two true meeting paths with full domain bounds); or EXPLICIT(n, finitely stated actual exact iterates reaching a smaller positive value). The checker **must derive** qlo/qhi, s/C/parities, child intervals, integrality, path equality and all inequalities itself. Use arbitrary precision; an overflow, missing tail, unverified machine integer conversion, unbounded iteration, certificate parse limit or recursion limit is FAIL/UNRESOLVED, not success. Every nonempty leaf must be proven; exhaustive hash Merkle commitments help audit identity and inclusion but **cannot replace the semantic proof**. A compressed DAG can share *proved identical* symbolic sublemmas, but cannot alias different clipped q ranges merely because residues/mod9 phases match (cf. R26's off-by-one alias).

**Complexity promise vs reality:** with V visited proof nodes, max depth K and max bit-length D, exact interval and affine verification takes at most O(V poly(K,D)) arithmetic bit operations, plus length of explicit paths and coalescence subproofs. A single accepted r=3 (mod 16) 4-step node represents one-sixteenth of an aligned 2^40 task, ~2^36 inputs, and its symbolic certificate is constant-sized; but that is a known simple reduction, NOT a new workload speedup. No proved universal upper on V substantially less than work-unit size, nor measured median V, bandwidth, wall time, memory or checksum-independent issuance exists. In the worst case, singleton leaves and long witnesses require O(2^40) or worse verifier work. Consequently **we have not discovered a generally succinct independent Collatz certificate**, only an exact sound certificate *language conditional on fully populated proofs*. Such a language may be cheap for some inputs and disastrous for hard residuals. GIMPS's special PRP proof and cryptomining shares have no transfer theorem to this language.

**Proof status labels:**
1. A fully checked algebraic proof DAG + accepted global strong-induction premises = **deterministic conditional mathematical certification**.
2. Same work unit run independently with source-distinct CPU/GMP reference or cross-vendor GPU engine, complete exception replay and matching canonical endpoint/work outcome = **independently reproducible exhaustive computation**, not automatically a compact proof and still conditional on A(B).
3. Matching summary hashes, 2-identity BOINC agreement, spot samples, mining shares, independent-looking machines with the same bug = **statistical/operational corruption detection only**. Neither no-Sybil nor numerical correctness follows from a quorum count.

Fallback until a proven efficient proof DAG: require *two complete source-independent passes* per task, ideally distinct toolchains/platforms; exact task bounds, integer semantics and abort/refuse records; full 128-bit/GMP exception queue on trusted independently recomputing arbiter; independent rebuild/source audits; canonical per-task and interval ledger; forbid accepting a conflicting quorum; adjudicate mismatches by a THIRD full independent run or stop. Distinct verified physical administration/operator identity, not merely distinct accounts, is needed for an anti-Sybil claim. Double replay protects against many faults, but shared assumptions, specification bugs and coordinated bad results remain. Never treat two matching 64-bit checksums as mathematical equivalence of complete trajectories or that this protocol has been implemented.
