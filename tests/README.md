# Tests

This directory will hold deterministic test assets and test code.

Required future categories include:

- exact unit identities;
- map-convention fixtures;
- macro-block state/count equivalence;
- independent reference-oracle comparisons;
- reproducible randomized differential tests;
- checkpoint round-trip/integrity tests;
- known trajectory fixtures;
- implementation-diversity checks where practical;
- below-scientific-scale validation ladders;
- result/manifest/schema validation.

No test fixture is a scientific CEML rung unless E1 explicitly says so.
